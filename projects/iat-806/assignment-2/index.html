Pop the Balls! 🎈

Assignment 2 — Body Game

My Game

How to Play

Pop the Balls! is an interactive body-controlled game created using p5.js and ml5.js. The webcam detects your body movements, allowing you to pop colorful balls by moving your arms and hands.

Your goal is to pop 20 balls in 30 seconds. Each popped ball earns one point. Reach 20 points before the timer runs out to win!

How It Works

The game uses the BodyPix body segmentation model to detect changes in the player's silhouette. Each ball is an object created using a JavaScript class. Balls are added and removed during gameplay, and the game includes start, playing, and game-over states.
